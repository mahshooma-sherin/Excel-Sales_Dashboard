# Excel Sales Dashboard

## About the Project

This project is an interactive Sales Dashboard created using Microsoft Excel.

## Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Slicers
- XLOOKUP
- Data Visualization

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Customer Segment Analysis
- Monthly Sales Analysis
- Product Performance
- Interactive Filters and Slicers
